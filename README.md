# dio-desafio-azure-openai

## Objetivo
Explorar o Azure OpenAI Playground, compreender seus parâmetros e gerar conteúdo utilizando a inteligência artificial da OpenAI via Azure.

## O que aprendi
Durante a exploração do Playground, pude testar diferentes configurações como:
- **Temperatura**: que altera a criatividade das respostas;
- **Comprimento máximo da resposta**: que limita a quantidade de palavras ou tokens;
- **Top P**, **Frequência** e **Presença**: que influenciam a variedade e repetição de palavras.
Com esses testes, percebi como pequenas alterações nos parâmetros impactam diretamente o estilo, o tamanho e o conteúdo das respostas geradas.
O Playground é uma ótima ferramenta para testar ideias e gerar conteúdos personalizados com IA.
